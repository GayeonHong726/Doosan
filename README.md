# 개인프로젝트 - 두산베어스 홈페이지 클론

### 프로젝트 개요
- HTML, CSS, JavaScript 를 활용해 두산 홈페이지를 클론하고, YouTube API 와 Google Maps API 를 사용하여 동적인 기능을 추가한 웹사이트입니다.

### 팀원
- 개인 프로젝트

### 작업 내용
1. 두산베어스 홈페이지 UI 구현
   - HTML, CSS 를 활용해 두산 공식 홈페이지와 유사한 레이아웃 및 디자인 적용
   - 반응형 웹 디자인을 고려하여 다양한 화면 크기에 보기 좋게 구성
![chrome_ctvguL4p36](https://github.com/user-attachments/assets/cad070f6-eec2-4b02-9112-3173f21bb055)

2. YouTube API 연동 (REST API)
   - Youtube Data API를 사용해 두산 공식 유튜브 영상의 최신 동영상을 자동으로 가져옴
![chrome_I8zkwHi8Ws](https://github.com/user-attachments/assets/29a47a48-0993-4b11-b172-1147e343467b)

3. Google Maps API 활용 (구장 위치 표시)
   - Google Maps API를 이용해 두산 베어스 구장들의 위치를 지도에 표시
   - 마커(marker)를 추가하여 사용자가 지도에서 홈구장을 쉽게 찾을 수 있도록 구현
![chrome_rHMhpSM5dg](https://github.com/user-attachments/assets/89d78acd-7785-4e52-9540-c324d9689d60)
